# Hangman Game – Python

## About the Project
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected hidden word by entering one letter at a time.

## Features
- Random word selection
- Five predefined words
- Six incorrect attempts allowed
- Hangman ASCII drawing
- Displays guessed letters
- Checks repeated letters
- Validates user input
- Win and lose conditions
- Play again option

## Technologies Used
- Python 3
- Random module
- VS Code

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python hangman.py
```
